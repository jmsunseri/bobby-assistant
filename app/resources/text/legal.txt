# Legal
## AI processing
AI processing is provided by Cloudflare Workers AI. Requests are sent directly from your phone to Cloudflare using the account and API token you configured. The Cloudflare terms that apply are at https://www.cloudflare.com/website-terms/ and the Workers AI terms at https://developers.cloudflare.com/workers-ai/platform/terms/.

## Weather
Weather data is provided by Open-Meteo (https://open-meteo.com/).

## Web search
Web results are provided by Brave Search (https://brave.com/search/api/).

## Currency data
Exchange rate data is provided by Exchange Rate API (https://www.exchangerate-api.com/).

## Maps and geocoding
Place-name geocoding is optionally provided by Mapbox (https://www.mapbox.com/).
